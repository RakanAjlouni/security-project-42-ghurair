Prototype Pollution

CWE-1321 · OWASP A08:2021 Software and Data Integrity Failures

In JavaScript, objects can inherit properties from a shared prototype. If untrusted input sets a key like __proto__ during an object merge, it can change the shared prototype and give other objects unexpected values—such as admin access.

Real-world impact

Why it matters

Polluting a shared prototype can affect many objects across the app at once—altering default options, bypassing checks, or causing unexpected errors. A well-known real-world example is CVE-2019-10744 in lodash, where unsafe merge or defaults helpers allowed prototype pollution.

              Code analysis
              
The vulnerable code

            


            

              

                
                  
                    
                  
                  VULNERABLE CODE · JavaScript
                

                
              


              
                function merge(target, source) {
                for (const key in source) {
                  if (typeof source[key] === 'object' && source[key] !== null) {
                    target[key] = target[key] || {};
                    merge(target[key], source[key]);
                  } else target[key] = source[key];
                }
              }
              const isAdmin = (user) => user.isAdmin === true;
            

            


            

              The merge helper follows keys like __proto__ or
              constructor.prototype into the shared prototype,
              and isAdmin accepts inherited properties instead of
              checking only the object's own properties.
            


          


          


            

              Remediation
              
The fixed code

            


            

              

                
                  
                    
                  
                  SECURE CODE · JavaScript
                

                
              


              
                const BLOCKED_KEYS = ['__proto__', 'constructor', 'prototype'];
                function safeMerge(target, source) {
                  for (const key of Object.keys(source)) {
                    if (BLOCKED_KEYS.includes(key)) throw new Error('Dangerous key rejected: ' + key);
                    if (typeof source[key] === 'object' && source[key] !== null) {
                      if (!Object.hasOwn(target, key)) target[key] = Object.create(null);
                      safeMerge(target[key], source[key]);
                    } else target[key] = source[key];
                  }
                }
                const isAdmin = (user) => Object.hasOwn(user, 'isAdmin') && user.isAdmin === true;
              

            


            

              Dangerous keys are blocked, nested objects use
              Object.create(null) without a prototype chain,
              and Object.hasOwn ensures admin checks ignore
              inherited values.
