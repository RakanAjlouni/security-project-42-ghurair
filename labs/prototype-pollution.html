Prototype Pollution

CWE-1321 · OWASP A08:2021 Software and Data Integrity Failures (verify mapping)

What it is

Prototype pollution (CWE-1321, Improperly Controlled Modification of Object Prototype Attributes) lets untrusted input edit the shared prototype that JavaScript objects inherit from. Every object then inherits the attacker's property, which can bypass checks such as isAdmin.

The vulnerable code

function merge(target, source) {
  for (const key in source) {
    if (typeof source[key] === 'object' && source[key] !== null) {
      target[key] = target[key] || {};
      merge(target[key], source[key]);
    } else target[key] = source[key];
  }
}
const isAdmin = (user) => user.isAdmin === true;

merge() follows the key '__proto__' (or constructor.prototype) into the shared prototype, and isAdmin() trusts inherited values. The demo uses an isolated prototype, not the real Object.prototype.

Why it matters

        

          One polluted prototype can grant admin rights to every object, change
          app behavior or cause crashes. The popular lodash library had this
          flaw in defaultsDeep (CVE-2019-10744).
        

      

      

        
The fix

        

          Switch modes below and re-run your last payload to see the difference.
        

        
const BLOCKED_KEYS = ['__proto__', 'constructor', 'prototype'];
function safeMerge(target, source) {
  for (const key of Object.keys(source)) {
    if (BLOCKED_KEYS.includes(key)) throw new Error('Dangerous key rejected: ' + key);
    if (typeof source[key] === 'object' && source[key] !== null) {
      if (!Object.hasOwn(target, key)) target[key] = Object.create(null);
      safeMerge(target[key], source[key]);
    } else target[key] = source[key];
  }
}
const isAdmin = (user) => Object.hasOwn(user, 'isAdmin') && user.isAdmin === true;

        

          Dangerous keys are rejected, new objects have no prototype
          (Object.create(null)), and the check reads only own properties, so
          inherited values can never grant access.
