Origin Validation Error

CWE-346 · OWASP A01:2021 Broken Access Control

When a page uses postMessage(), any open website can send it data. If your code does not check who sent the message (event.origin), a bad site can trick your app into moving money or changing settings for the visitor.

Real-world impact

Why it matters

If a page trusts any sender on postMessage, a malicious site opened in another tab or frame can trigger actions or send forged data on behalf of the visitor. Missing origin checks in postMessage handlers is a well-known web vulnerability that has exposed sensitive actions and data across real-world web apps.

Code analysis

The vulnerable code

VULNERABLE CODE · JavaScript 
                let balance = 1000;
                window.addEventListener('message', (event) => {
                  // No check on event.origin before trusting the message
                  const message = event.data;
                  balance -= message.amount;
                  render();
                });

                function render() {
                  document.getElementById('balance').textContent = balance;
                }

The listener reads event.data right away without checking event.origin. Any other website can send a message and lower the user's balance.

Remediation

The fixed code

SECURE CODE · JavaScript 
                const ALLOWED_ORIGINS = ['https://app.iwss.example'];
                let balance = 1000;

                window.addEventListener('message', (event) => {
                  if (!ALLOWED_ORIGINS.includes(event.origin)) return;
                  const m = event.data;
                  const valid = m && m.type === 'transfer' &&
                    Number.isFinite(m.amount) && m.amount > 0 && m.amount <= balance;
                  if (!valid) return;
                  balance -= m.amount;
                  render();
                });

The code checks event.origin against an exact list of trusted sites and makes sure the transfer amount is a valid positive number before changing the balance.
